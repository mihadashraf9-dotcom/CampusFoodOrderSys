 Campus Food Order System

This project was created for the Design Patterns assignment.

The project demonstrates:
 Factory Pattern
 Singleton Pattern

The system includes different notification types such as:
Email notifications
SMS notifications
Push notifications

Language used:
Java

IDE used:
Eclipse

How to Run:

1. Open the project in Eclipse.
2. Run CampusFoodOrderService.java as a Java Application.
3. The program will display notification messages in the console.

Expected Output:

The program should show notifications such as:
Email notification sent
SMS notification sent
Push notification sent
